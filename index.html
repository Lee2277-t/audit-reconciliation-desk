Step 01 · 导入对账数据

表格不上传 · 本机计算 · 关闭后不保留

拖入 Excel 文件，或 点击选择
可一次选择两个文件；同一工作簿里的应收、应付两张表会自动一起导入

从 Excel 分别复制两列（企业名称、金额），粘贴到左右两侧即可。首行表头、合计行会自动跳过；某行名称留空时，自动承上一行。

应收账款 企业名称 + 金额
0 行右侧写应付，不要混在一起
应付账款 企业名称 + 金额
0 行留空也可以，但会全部标为单边
表格可以这样准备
  1. 方向可以没有：工作表名或文件名含“应收账款 / 应付账款”就能识别；一个工作簿里放两张表最省事。
  2. 企业名称：支持合并单元格。企业名只写一次、下面几行留空，工具会自动继承上一行。
  3. 金额：数字、文本金额、千分位、括号负数都能识别；导入后可选择元、千元或万元。负数会取绝对值并自动改记到对立方向（应收负数记应付、应付负数记应收）。红字金额（数字本身是正数、只是字体标红）也按负数处理，明细里会标「红字转负」。
  4. 方向列：如果有“应收/应付”列也可以直接选；没有就按表名或整表方向判断。
  5. 整本工作簿：一次导入多个工作表时，默认一张都不勾；要核对哪几张就自己勾。封面、目录、试算表也不会自动参与，可用「全选」按钮一次性勾上，再取消不要的。
  6. 两行表头也认得：像“本期未审｜期初金额 期末金额”这种上下两行的表头，工具会合并成完整列名再判断。
  7. 直接复制到 Excel：展开任一企业的明细，上方有应收、应付两个复制区，点“复制”后到 Excel 里 Ctrl+V，会自动分成 5 列（企业名称 / 金额 / 摘要 / 数据源 / 原表行）。

表头不必在第一行；每一列也可以手动重新指定。也可以切换到“手动粘贴”，左右两侧各粘两列。

01

双侧都能进

支持一个工作簿里的应收、应付两张表，也支持两个文件；还可以左右两栏直接粘贴。

02

方向自己判断

没有方向列也能从“应收账款底稿”“应付账款底稿”等工作表名、标题或文件名识别应收应付。

03

合并单元格照读

企业名称合并多行时，空白名称自动继承上一行；一家企业多笔金额会照常汇总并标记异常。

第一次用？先看这三步
  1. 放进数据。把应收、应付两张表（或一个工作簿里的两张表）拖进上面的虚线框；不想找文件就点「先跑一遍内置示例」，企业名都是编的，20 秒看完整流程。
  2. 核对一下。导入后先看每张表的图片：框住的那块就是会被计算的行；方向、单位不对就手动改；认列没把握时，看有没有「是猜的」的橙色提示。
  3. 对账导出。点「开始对账」，看结果页的净额和标记；重点复核的企业逐个点开，明细上方有「复制」可以直接贴进 Excel；最后用「导出工作簿」出底稿。

怎么打开？网页版打开网址就能用，手机也可以。软件版安装后从桌面或应用列表打开。使用免安装压缩包时，解压后双击 index.html；Windows 也可以双击 打开对账工具.bat。若公司电脑限制安装，请直接使用网页版。

能用什么浏览器？新版 Edge、Chrome、Firefox、Safari 都可以，IE 用不了。拿不准就点下面的「检查运行环境」，会逐项告诉你缺什么、该换什么。

数据会传出去吗？表格和对账结果不会上传。网页版打开时需要加载页面文件，之后的取数和计算都在你的设备上完成；软件版不用联网也能对账。关闭后不会保留底稿，要留档请先导出。

结果准不准？工具只做归并和提示，最终以人工复核为准；导出工作簿的「对账说明」页写清了每一条口径。

数据不出这台电脑

页面只从本机加载，不请求任何外部网站，也不使用统计、在线字体或在线图标。表格和结果只在这台电脑的浏览器内存里，关掉页面就没有了。

    上面每一行的「净额」是把这家企业的应收合计和应付合计大减小算出来的，只用来排差异和准备函证；它不代表这两笔可以抵销，账上要不要抵销得看合同里有没有抵销权、报表怎么列报。明细里的「自动核销」也只是提示，点「采纳」不会改动任何金额。

    底稿信息（会一起导出和打印） 填了就行，不填也能用；导出 Excel 的「对账说明」第一屏就是这几项。
    底稿快照（可选） 把这次结果存成一个小文件；下次改完再拿它比一比，哪些企业、哪些金额、哪些说明变了会列出来。快照文件含企业名称和金额，请按底稿保管。
    两次都用同一版工具保存，比较结果最可靠；比对只列变化，不改任何金额。
    导出文件校验码（可选） 每次导出后会按文件本身算一串校验码。把它记在底稿上，以后选回那个文件，就能核对是不是同一份；另存、编辑或重新导出都会变。
    计算口径与标记说明
    重复企业：归一后同一企业出现 2 笔及以上记录，已合并计算净额。
    同额对冲：同一企业内应收和应付出现完全相同的金额。
    同向重复：同一方向、同一金额出现两次及以上，可能存在重复入账。
    单边记录：该企业只有应收或只有应付，没有另一方记录。
    名称不一：归并为同一企业，但原表写法不同，建议核对是否同一主体。
    重点复核：命中“同向重复”“名称不一”或“负数重分类”的企业。
    净额口径：净额 = 应收合计 − 应付合计；金额按分计算，展示保留两位小数。净额只是对账归并口径，不代表会计上的抵销，能否抵销要看是否有法定抵销权和报表列报要求。
    取数核对：把金额列每一格重新扫一遍，要求「原表金额 = 已算进去 + 跳过的 + 范围外的」，差额必须是 0；不为 0 说明有金额没被算进来，展开能看到是哪几行。
    已人工并归：名称写法不同、由你在「名称相近」里点「是同一家」合并的企业，原始写法保留在明细里，可以一键撤销。
    同单据号：摘要里出现同样的发票号／单据号／凭证号，两侧对上号的会单独列出；金额不一致的就是只核销了一部分，请按凭证补差。
    摘要线索：摘要里写了同一个合同、项目、工程、部门、订单或批次，两侧会对出来放在一起方便对照；这只是文字上的线索，不代表是同一笔业务。
    负数重分类：负数金额取绝对值后自动改记到对立方向（应收负数记应付、应付负数记应收），请结合凭证复核。
    红字转负：金额本身是正数、原表用红色字体表示负数，工具按负数处理并重分类；如果红字只是标注，请改回普通颜色再导入。
    可自动核销：同一企业内找到金额相符的应收/应付组合，先一对一、再「多笔对一笔」凑数；展开明细可看具体配对，净额仍按企业合计大减小。
    差一点就能配上：自动配对没吃掉的记录里，两边金额只差一点的一对（差额不到当前容差的两倍，或者不到较大一方的 5%）。展开会在配对区写上「把核销容差改成多少就能配上」，这只是给个参照，不改变任何金额。
    账龄分布：原表写了账龄档位（如「1年以内」「1-2年」）、逾期天数或发生日期的，自动归到「1年以内／1-2年／2-3年／3年以上」四档；按日期推算的以「账龄算到」那天为准，一般填资产负债表日。原表没写的那笔单列示，不会硬塞进某一档；整张表没有账龄列时不提账龄。账龄只是把挂账时间分开看，不改变任何金额。

    结果仅供参考：工具只做归并与提示，不能替代审计程序，也不作为审计证据；净额是按企业大减小算出来的对账口径，不等于会计上可以抵销，最终金额与结论请以人工复核和原始凭证为准。
